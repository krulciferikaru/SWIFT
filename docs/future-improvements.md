# Future improvements

Ideas raised during the evaluations that are **not built yet**. They are here so they are not lost.

| Idea | Notes |
|---|---|
| **Email reminders before the due date** | Reminders go out by SMS today (see [Automated jobs and SMS](automation.md)). Sending the same reminder by email was suggested as an extra channel. It needs an email service and each subscriber's email address, which is optional today. |
| **Online payment** (GCash, InstaPay, QR Ph) | Subscribers cannot pay inside the system. Payments are recorded by staff after cash or GCash is received. |
| **SMS to all mobile networks** | PhilSMS currently reaches Globe numbers only. Other networks need a different provider or plan. |
| **Barangay dropdown for addresses** | On hold: not every barangay in Palayan City should be listed yet, so the list has to be agreed first. |
| **Company contact information** in the system and on receipts | Skipped for now. |
| **Per-module View / Edit / Delete levels** | Permissions are switches per task today. Separate levels inside every module would be new development. |
